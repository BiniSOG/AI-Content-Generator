# Report outline (1–2 pages; export as PDF)

Write it in your own words. Cite files and entries, e.g. "EXPERIMENTS E05", "FAILURES F03", "DESIGN Test 1, person 2".

1. **What I set out to make, and for whom.** Two or three sentences, matching DESIGN.md §1.
2. **What my audience told me and what changed.**
   - Test 1: quotes → the storyboard changes (commit).
   - Test 2: quotes → the final changes.
3. **The hardest problem and how I solved it.** One problem, told concretely, pointing at FAILURES.md.
4. **A suggested practice that beat my instinct.** Evidence. Candidates: a radio cut before pictures; a reference sheet before keyframes; describing only motion in i2v prompts; ducking.
5. **A suggested practice that didn't work for me.** Evidence. Be candid.
6. **Ceiling work.** E07 language test: a table of languages × native rating × the problems found, and what it means for people making films in those languages.
7. **What I'd build next.**
8. **Links:** the repo, the 9:16 film, the 16:9 film, the walkthrough, the post.
